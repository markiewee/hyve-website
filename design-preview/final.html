Lazybee · identity · production

The mark, drawn properly.

Seven points, weighted so the two long ones read as wings, the pair above as antennae, the pair below as legs and the one straight down as the stinger. No body drawn. A brass dot above does the head. Geometry is generated from one set of numbers, so every weight is the same shape with a different taper.

05 · files

What is on disk

All in design-preview/assets/. The mono versions use currentColor, so they take the colour of whatever they sit in. The wordmark stays as live text in Italiana rather than outlines, so it can be selected, translated and searched. Outlines only get cut when something goes to a printer.
