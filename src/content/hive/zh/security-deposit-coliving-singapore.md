新加坡共居房间收取的押金几乎总是一个月租金。无论你租的是合租单位里的一个房间，还是自己租一整套单位，这都是市场通行做法。法律并没有规定具体金额，这只是大多数租赁合约和许可协议约定俗成的数字。除非房东能证明存在超出正常损耗的实际损坏，否则押金应全额退还。

真正重要的不是金额，而是搬走时会发生什么，以及你在入住时有没有做好那些小事，让退款变成自动流程，而不是一场争执。

## 押金到底是用来做什么的

押金的作用只有两个：抵扣租期结束时的欠租，以及赔偿超出合理损耗范围的损坏。仅此而已。它不是清洁基金，不是房东日常开支的缓冲，也不是因为租约结束得不愉快房东就可以扣下的钱。

新加坡没有专门的租赁法。押金问题适用一般合同法，实际规范金额、退还条件和时间线的是你的租赁合约或许可协议条款。法律没有规定房东可以收取的押金上限，这正是为什么这条条款要在签字前读清楚，而不是等付了钱之后才看。

## 2026年新加坡各营运商的押金惯例

2026年，一个月租金是新加坡整体房间出租和共居安排的标准押金。整套单位出租有时会按租期长短调整，两年租约常见两个月押金。但对合租单位里的单个房间来说，这种按长租期计算的逻辑大多不适用，因为大多数共居许可协议都是按月或较短的固定期限运作。

如果租客的租期较短，或者背景较难核实（没有本地担保人、第一次在新加坡租房），有些营运商会要求更高押金。这是各营运商自行判断的结果，而不是硬性规则。Lazybee所有房间统一收取一个月押金，退还流程每次都按同一套检查清单执行。

## 共居押金与整租押金的区别

这两者虽然在纸面上看起来一样，但其实不完全是同一回事。

**整租押金。** 你是唯一的租客，所以押金只需要对你造成的损坏负责。入住和搬出时拍照都比较简单，因为只需要核对一个人的使用情况。

**合租单位的房间押金。** 你的押金覆盖你的房间以及你在公共区域应承担的部分。公共区域的损坏在多人共用的情况下比较难以归责。运营规范的营运商会用逐租客的照片记录和清晰的房屋守则来处理这个问题，让你的押金不会因为别人弄出来的问题而受损。签约前先问清楚这方面是怎么处理的。

| | 整租押金 | 合租单位房间押金 |
|---|---|---|
| 常见金额 | 一个月，两年租约有时为两个月 | 固定一个月，无论住多久 |
| 承担范围 | 你造成的损坏，因为你是唯一租客 | 你的房间加上你在公共区域应承担的部分 |
| 举证情况 | 简单，只需核对一个人的使用情况 | 较复杂，因为多人共用公共空间 |
| 签约前该问什么 | 退款条件与时间线 | 营运商如何归责公共区域的损坏。运营规范的营运商会用逐租客的照片记录和清晰的房屋守则，确保你的押金不会因别人的问题而受损 |

## 房东常试图扣除、但其实不该扣的8项费用

如果房东在你搬出时提出以下任何一项，请据理力争，要求对方指出合约中支持这项扣款的条款。

1. **整套单位重新粉刷。** 因日常日照和时间导致的油漆褪色属于正常损耗，不是损坏。
2. **整块地毯更换**，如果损耗只是正常租期内日常走动造成的磨损。
3. **专业清洁费**，如果房间搬出时已经保持基本整洁。要求做一次简单清洁是合理的，但除非合约另有明确规定，否则要求一整张专业清洁发票通常不合理。
4. **挂画或置物架留下的小钉孔**，已经正常修补的情况。
5. **灯泡损坏或电器老化失灵**，是使用年限到了，不是使用不当造成的。
6. **超出合约约定义务的冷气维修。** 许多合约把日常保养责任放在租客身上，但如果是一台用了十年的机组压缩机整体维修，那不属于你造成的损耗。
7. **仅因外观刮痕就更换家具**，而不是真的损坏。
8. **没有收据或明细、笼统的一笔扣款。** 任何扣款都必须有书面说明和凭证支持。

## 误解：合理损耗可以随房东自行定义

这是错的。「合理损耗」有明确而狭窄的含义：指在整个租期内因日常正常使用而产生的自然老化。这个说法不是任何一方可以随意拉伸解释来迎合自己利益的。

| 合理损耗 | 损坏 |
|---|---|
| 因日常日照和时间导致的墙面褪色 | 门上被打穿的一个洞 |
| 因日常走动形成的地毯磨损痕迹 | 台面上的烧焦痕迹 |
| 因多年使用而松动的橱柜铰链 | 被打破的窗户 |
| 灯泡损坏或电器因使用年限到了而失灵 | 因使用不当而损坏的电器 |
| 挂画留下、已正常修补的小钉孔 | 真正损坏而非表面刮痕的家具 |

举证责任在房东这边。如果房东要扣款，必须证明损坏程度超出正常使用范围，而不是单方面说说就算数。「我不喜欢它看起来的样子」不属于损坏的范畴。

## 你入住时忘记拍的那些照片

几乎每一起押金纠纷追根究底都是同一个原因：没有人能证明房间在入住第一天的状态。在你打开第一个行李箱之前，先拍下以下内容。

- 每一面墙，从这个角落到那个角落，包括天花板角落，那些地方容易藏霉斑或裂缝。
- 地板，尤其是门边和整个租期内都不会挪动的家具底下。
- 每一件电器，开机通电状态，附带时间戳。
- 已有的刮痕、污渍或痕迹，拍近景，以免日后有人说是你造成的。
- 屋内配备的所有家具，包括床垫底部和衣柜内部。

当天就把这些照片通过WhatsApp或电邮发给房东或营运商，让双方都有带时间戳的记录。入住时花五分钟拍照，是你为这几百块钱押金买到的最便宜的保险。

## 保护押金的搬出检查清单

在交还钥匙之前完成这份清单，而不是之后才做。

- [ ] 按入住时相同的角度、相同的顺序，重新拍一遍照片。
- [ ] 清空所有个人物品，包括抽屉里和床底下藏的东西。
- [ ] 做基本清洁：擦拭台面、扫地、清空垃圾桶。除非合约特别要求，否则不需要请清洁工。
- [ ] 检查每件电器是否仍能正常使用，并上报任何故障。
- [ ] 归还所有钥匙、门卡和感应扣，并索取书面确认。
- [ ] 离开前索取书面的押金退还时间表，而不是两周后再去追问。
- [ ] 保留交接过程中的每一条消息记录，直到押金真正到账为止。

## 关于押金，你在法律上的处境

没有任何政府机构直接监管押金事宜。真正保护你的是你的租赁合约或许可协议、合同法，以及必要时的小额索偿庭。

- **没有法定押金上限**，但市场惯例是房间租赁的押金保持在一个月租金左右。
- **任何扣款的举证责任都在房东身上。** 没有明细清单和收据支撑的笼统说法站不住脚。
- **小额索偿庭受理押金纠纷**，索偿金额上限为S$20,000，若双方书面同意可提高到S$30,000。提出申请不需要律师。
- **从纠纷发生之日起你有两年时间**可以向索偿庭提出申请，所以房东拖延不是放弃的理由。
- **退款时间线没有法律规定**，但大多数合约会写明搬出后7到30天左右退还。如果你的合约没有写明，交还钥匙前要索取书面日期。

|---|---|
| 法定押金上限 | 不存在。市场惯例是房间租赁押金保持在一个月租金左右 |
| 举证责任 | 在房东一方。没有明细清单和收据支撑的笼统说法站不住脚 |
| 纠纷处理渠道 | 小额索偿庭，索偿金额上限为S$20,000，若双方书面同意可提高到S$30,000。提出申请不需要律师 |

| 适用框架 | 没有专门的租赁法。押金适用一般合同法，实际规范金额、条件和时间线的是你的合约 |

带日期的消息记录、入住照片、搬出照片，加上你书面索取退款日期的记录，这些都能让小额索偿庭的申请快速处理，而不是变成一场没完没了的各说各话。

## 常见问题

**共居房间的押金应该是多少？**
2026年，一个月租金是新加坡共居房间的标准押金。如果租客背景正常，却被要求明显更高的押金，值得直接问清楚原因。

**新加坡法律要求一定要收押金吗？**
不。法律并没有强制要求收取押金。这是一项合约条款，已经成为几乎所有市场都采用的惯例，但不是法律要求。

**房东可以从押金里扣清洁费吗？**
只有在房间搬出时没有保持基本整洁，或者合约明确规定你需要支付专业清洁费用的情况下才可以。房间保持整洁的话，不应该被扣清洁费。

**如果我搬出后房东一直不回复怎么办？**
发一条书面跟进消息，附上你的照片，并明确要求退款日期。如果还是没有回应，小额索偿庭可以受理最高S$20,000的索偿，不需要律师。

**共居房间和整租单位的押金金额有区别吗？**
绝对金额上差别不大。整租押金有时会随租期长短调整（两年租约通常是两个月），而共居房间的押金则大多固定为一个月，不论你住多久。
