新加坡的博士助学金大约在每月 S$2,000 到 S$3,800 之间，具体看学校、公民身份，以及你有没有通过资格考试。以这样的收入，私人工作室公寓对大多数学生来说都租不起，但组屋（HDB）里的普通房、私人公寓里的合租房间，或者共居空间里的一个床位，都是现实的选择。最终怎么选，通常取决于你需要离校园多近，以及你愿意为了从零开始安家花多少工夫。

这不是一篇带百分比和公式的预算拆解文。这是对新加坡博士生住房的直白梳理：助学金实际发多少，这笔钱在当前租房市场能租到什么，以及博士生最后一般都住在哪里。

## 新加坡的博士助学金实际发多少？

在新加坡国立大学，从 2026 年 1 月 1 日起，领取研究奖学金的博士生每月可拿 S$3,800（新加坡公民）、S$3,400（永久居民）、S$3,000（国际学生）。学费另行覆盖。通过资格考试之后，奖学金获得者每月可再多拿 S$500，资格考试通常在第一年或第二年的某个时间点完成。

在南洋理工大学，研究奖学金的起点低一些：公民每月 S$2,700，永久居民 S$2,200，国际学生 S$2,000，通过资格考试后最多再加 S$500。南洋理工大学的南洋校长研究生奖学金起薪水平相近。部分南洋理工大学的项目，比如国立教育学院的博士方向，视资金来源而定，接近 S$3,000 到 S$3,800。

|---|---|---|---|---|
| 新加坡国立大学研究奖学金，自 2026 年 1 月 1 日起 | S$3,800/月 | S$3,400 | S$3,000 | 每月最多再加 S$500 |
| 南洋理工大学研究奖学金 | S$2,700/月 | S$2,200 | S$2,000 | 最多再加 S$500 |
| 南洋理工大学南洋校长研究生奖学金 | 起薪水平相近 | | | |
| 南洋理工大学国立教育学院博士方向 | S$3,000 到 S$3,800，视资金来源而定 | | | |

新加坡国立大学的学费是另行覆盖的。南洋理工大学第一年的国际学生拿 S$2,000，而新加坡国立大学已通过资格考试的本地学生拿 S$4,300，两者差距很大，你落在这个区间的哪个位置，几乎决定了之后所有的住房决策。

## 这笔助学金在新加坡租房市场究竟能租到什么？

截至 2026 年年中，组屋里的普通房月租大约在 S$800 到 S$1,300 之间，多数非中心区域集中在 S$900 上下。私人公寓里的普通房则更接近 S$1,300。主人房，也就是带独立卫浴的较大房间，价格更高，在私人公寓里常常超过 S$2,000。

组屋普通房价格较低的区域通常是蔡厝港、兀兰、义顺、裕廊西和后港。价格较高的则在比较中心或成熟的区域，比如女皇镇、红山、加冷和大巴窑。这些还不包括水电、无线网和任何中介费，组屋房东并不总会把这些打包在租金里。

| 房型 | 典型月租 | 备注 |
|---|---|---|
| 组屋普通房 | S$800 到 S$1,300，多数非中心区域集中在 S$900 上下 | 蔡厝港、兀兰、义顺、裕廊西、后港最便宜。女皇镇、红山、加冷、大巴窑较贵。水电、无线网和中介费通常不含在内 |
| 私人公寓普通房 | 接近 S$1,300 | 含小区设施 |
| 私人公寓主人房 | 常常超过 S$2,000 | 面积更大，带独立卫浴 |

对照上面的助学金数字，一间普通房会吃掉助学金的四分之一到一半，而这还没算伙食、交通和其他所有开销。

把数字和上面的助学金对照一下，情况就很清楚了。一间普通房会吃掉助学金的四分之一到一半，而这还没算伙食、交通和其他所有开销。这是一个实打实的约束，不是小问题，签任何合约之前值得先想清楚。

## 押金、中介费和租期是怎么回事？

新加坡多数组屋普通房出租都会要求押金，通常是一到两个月租金，如果房间是通过房产中介找到而不是直接向房东租的，还要加上中介费。标准租期是六个月到一年，提前解约通常意味着押金不退，除非你的租赁合约另有约定。

这笔前期现金支出让不少刚入学的博士生措手不及，尤其是那些还没有新加坡银行账户、也还没有本地担保人的国际学生。有些房东在把房间租给学生之前，还想看到收入证明或奖学金证明信，所以开始看房之前，最好先把录取信和助学金确认文件准备好。

共居营运商的做法通常不一样。租期一般更短更灵活，押金更低或更简单，而且因为房间是带家具的、水电和无线网已经包含在租金里，所以不用另外付路由器押金，不用开公用事业局账户，来到新加坡的第一周也不用张罗家具。

## 要不要先争取校内宿舍？

值得申请，但别指望它。新加坡国立大学对第一年的博士生在大学城住宿方面给予特别考虑，但只覆盖头两个学期，而且校方自己也说每一届的需求都超过供给。不是每个申请者都能拿到房间，新加坡国立大学明确建议学生同时在校外找房，而不是干等结果。

南洋理工大学也有自己的宿舍和研究生公寓，限制类似：床位有限、有优先级分层，过了第一或第二年就没有保证。把校内住宿当成锦上添花，而不是基本方案。无论如何，都要先备好一个校外选项。

## 以博士生的预算，哪些区域比较合理？

对新加坡国立大学的学生来说，金文泰、多佛、波那维斯达和巴西班让离肯特岗只有一小段巴士或地铁路程，普通房供应量不错，也没有最中心区域的溢价。对南洋理工大学的学生来说，文礼、先驱和整个裕廊一带，让你在环线或东西线上靠近校园，又不用付中心区的租金。

如果你愿意为了明显更低的租金多通勤一点，北部和东北部走廊，比如义顺、兀兰、实龙岗和后港这些区域，组屋普通房的价格一贯低于全岛平均。不少博士生最后选择在地铁上多花二十分钟，换每月省下几百块，四年的博士生涯累积下来相当可观。

## 什么房型才真正配得上一份助学金？

组屋里的合租普通房是进入体面住房最便宜的方式，但你要接受一个自己无法掌控的室友环境、一段没有专业管理背书的房东关系，以及一份租期往往超出博士第一年实际所需的合约。共居里的独立房间比最便宜的组屋普通房贵，但比私人公寓主人房便宜，而且租期更短更灵活，是有人管理的社群而不是随机拼凑的合租，也完全免去了新租组屋要买家具、开水电账户的那一套。

| | 组屋普通房 | 共居房间 |
|---|---|---|
| 租金 | 进入体面住房最便宜的方式 | 比最便宜的组屋房间贵，比私人公寓主人房便宜 |
| 押金 | 通常一到两个月租金，若通过中介找房还要加中介费 | 通常更低或更简单 |
| 租期 | 六个月到一年。提前解约通常押金不退 | 更短更灵活 |
| 安置 | 自己买家具、开公用事业局账户、安排无线网 | 带家具，水电和无线网包含在租金里 |
| 室友 | 一个你无法掌控的环境 | 有人管理的社群 |
| 房东 | 个人，没有专业管理背书 | 营运商 |
| 新到者的门槛 | 有些房东要求收入证明、奖学金证明信、本地担保人或新加坡银行账户 | 一般更少 |

多数博士生最后会落在这两个选项之间的某个位置，取决于他们有多看重灵活性、又有多在意把价格压到最低。两种都没有错。这是一个真实的取舍，在签下一份难以中途退出的一年期合约之前值得掂量清楚，毕竟你的研究可能让你出国待一个学期，你的经费状况也可能变化。

## 多数博士生实际上都是怎么做的？

实际情况是，很多第一年的博士生会先接受学校给的任何校内住宿，因为便宜，而且在你还要适应实验室、导师和一套全新的学位结构时，这样能少操一份心。等第一年的优先窗口结束，多数人就搬到校外，而上面那些取舍也正是从这时开始变得重要。

在新加坡没有既有人脉的国际学生，往往倾向于共居或通过中介找房，因为这两者都有别人替你处理杂事。本地学生和永久居民通常已经有家人、朋友，至少有银行账户和担保人，更可能直接去租组屋普通房，为了更低的租金接受多跑腿。

哪条路都算不上「正确」。这取决于你在头几个月里觉得自己的时间值多少钱，以及你想把每月这个数字压低多少。
