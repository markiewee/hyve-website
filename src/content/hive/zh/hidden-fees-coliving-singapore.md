报出来的房间价钱，很少就是最终要付的数目。新加坡的共居房间可能在租金以外还有其他收费：行政费或登记费、清洁费、超出上限的水电费、中介费、钥匙或门禁卡费用，以及提前解约时的违约金。这些费用本身都不必然不老实。有些是行业标准，也合理。有些则是叫你转身走人的信号。要分辨两者，唯一的办法就是在签字之前，把每一项费用都要来，白纸黑字写清楚。

这篇文章不是要针对哪一家营运商。只要越过标价看下去，整个市场都有各种费用，包括一些标榜全包的房源。下面这份清单，是拿来跑任何一份合约、任何一家营运商用的，好让你在看房时谈好的数字，就是你实际付出的数字。

## 可能叠加在租金之上的完整费用清单

不是每个房源都会收齐这些。多数只收其中几项。逐条走一遍，直接问清楚哪些适用于你的房间。

1. **行政费或登记费。** 一次性收取，用于处理你的申请和文件，有时会和合约本身打包在一起。
2. **清洁费。** 可能是公共区域清洁的经常性收费，也可能是退租时另外从押金里扣的一次性清洁费。
3. **水电上限超额。** 租金已包含一定额度以内的电和水，超出额度的用量会另外向你收取。
4. **网络费。** 在成熟的营运商那里少见，但有些会另外收费，或者以加购的方式提供「高级」的更快网速。
5. **冷气保养费。** 季度保养、加雪种或化学清洗，在有些合约里是与租金分开计算的。
6. **押金相关收费。** 不是押金本身，而是围绕押金的附加项目：押金「处理」费，或者一开始就划走的不可退还部分。押金规则以及退还时法律上允许扣除的项目，我们在[押金指南](https://lazybee.sg)里有完整说明，所以这篇只点出围绕押金叠加的费用，不谈押金机制本身。
7. **提前解约费。** 在租期结束前中止合约要付的费用，有时是一笔固定金额，有时是没收押金。提前结束共居租约的法律细节另有专文说明，这里只是清单上的一项，你要确认它存不存在、金额是多少。
8. **中介费或推荐费。** 在房源平台和传统由中介经手的出租上比较常见，直接对接营运商的平台上比较少见。
9. **钥匙、门禁扣或门禁卡费用。** 发放门禁卡或钥匙的收费，或者遗失后的补办费。
10. **洗衣费。** 楼里的投币式或应用程式洗衣设施，按次收费，而不是包含在租金里。
11. **逾期付款费。** 租金过了到期日才入账的罚款，通常是一笔固定金额或按日计算的小额费率。
12. **访客或留宿费。** 有些楼盘对留宿访客收费，或者要求为访客门禁卡缴付押金。

| 费用 | 是什么 | 判断 |
|---|---|---|
| 行政费或登记费 | 一次性收取，用于处理你的申请和文件 | 值得多问一句。金额不高又在你承诺之前说清楚，就没问题 |
| 清洁费 | 公共区域的经常性清洁，或退租时的一次性清洁 | 值得多问一句。金额固定就没问题，不能写成开放式的「按实际成本」 |
| 水电上限超额 | 租金包含一定额度以内的电和水，超出部分向你收取 | 属于标准做法，前提是上限和超额费率都写成具体数字 |
| 网络费 | 另外计费，或付费的「高级」更快网速 | 在成熟的营运商那里少见。问清楚为什么要单独收 |
| 冷气保养 | 季度保养、加雪种或化学清洗 | 属于标准做法，包含或另计都行，只要金额写清楚 |
| 押金相关附加项 | 押金「处理」费，或一开始就划走的不可退还部分 | 要问到底。这与押金本身是两回事 |
| 提前解约 | 提前中止租约要付的固定金额、没收押金，或两者都有 | 值得多问一句。如果在全额没收押金之外再叠加，就是危险信号 |
| 中介费或推荐费 | 经纪佣金 | 在房源平台上比在直接对接营运商的平台上常见 |
| 钥匙、门禁扣或门禁卡 | 发放或补办你的门禁 | 属于标准做法。这是营运商本来要自己承担的真实成本 |
| 洗衣费 | 投币式或应用程式，按次收费 | 楼里设有共用洗衣机的情况下属于标准做法 |
| 逾期付款 | 租金过了到期日才入账的罚款 | 金额合理的固定收费属于标准做法。任何会滚存的百分比都要追问 |
| 访客或留宿 | 留宿访客收费，或访客门禁卡押金 | 视楼盘而定。不要想当然以为访客免费，先问清楚 |

## 哪些属于标准做法，哪些是危险信号

清单上的费用，意义并不一样。有些只是普通的成本回收。有些则是一份糟糕合约悄悄把你月付数字撑大的手法。

**通常属于标准，可以预期会有：**
- 水电上限搭配清楚的超额定价，事先说明
- 冷气保养，包含在租金里或另外计费都行，只要金额写清楚
- 逾期付款费，前提是一笔合理的固定金额，而不是会滚存的百分比
- 钥匙或门禁卡遗失的补办费，因为这本来是营运商要自己吸收的真实成本

**值得多问一句，但不必然不好：**
- 一次性的行政费或登记费，只要金额不高，并且在你作出承诺之前就说清楚，而不是签约当天才冒出来
- 提前解约费，前提是金额和触发条件都写进合约，而不是含糊带过
- 退租清洁费，只要是固定、合理的金额，而不是开放式的「按实际成本」

**危险信号：**
- 任何在签约桌上才第一次提起的费用，看房时和房源资料里都没有出现过
- 清洁费或行政费没有固定金额，只说「届时评估」
- 提前解约费叠加在全额没收押金之上，等于为同一次退租向你收两次钱
- 水电上限没有写明超额费率，让你算不出最坏情况下的账单
- 任何你直接开口问，营运商却不肯写下来的费用

每一个危险信号的模式都一样：真实、事先披露的数字没问题。含糊、没披露，或者临门一脚才冒出来的，就有问题。

## 为什么「全包」不一定代表没有额外费用

「全包」讲的是基本租金里包含了什么，不一定涵盖整个租期内所有可能出现的收费。一个房源可以在网络、水电和清洁上真的做到全包，同时仍然有单独的提前解约费或钥匙遗失费，因为这些不属于每月打包的部分，而是只在特定情况下才发生的条件性收费。两者回答的是不同问题。租金里包含什么是一份清单。还有什么可能另外向你收费，是这一份。

Lazybee 的房间把网络、水电、公共区域清洁和冷气保养都包进月租里，等于直接砍掉这份清单上的好几项。这是刻意的选择，不是宣称世上所有费用都会消失。像门禁卡遗失补办或提前解约费这类条件性收费，在确实构成真实成本的地方仍然存在，而且写在合约里，不会留成一个惊喜。目前的房间和条款可以在 [lazybee.sg](https://lazybee.sg) 查看。

## 费用审查：任何合约都可以跑的 6 个步骤

签任何东西之前做这件事，不是签完之后。

1. **逐项点名，要求书面列出所有费用。** 不要接受「都包含在内」这种答案。具体地问：行政费、清洁费、水电上限和超额费率、冷气保养、提前解约条款、钥匙或门禁卡费用、逾期付款条款。
2. **水电上限和超额费率要数字，不要描述。**「合理使用」不是一个数字。问清楚上限是多少元或多少度电，超出后每单位要付多少。
3. **逐行读提前解约条款。** 看清楚金额是多少、会不会与没收押金叠加，以及你要提前多久通知。
4. **确认费用写进了合约，而不是只用嘴讲。** 看房时说过但没有写进合约的，都没有约束力。既然值得你开口问，就应该出现在文件里。
5. **把每一项已披露的费用加到标价租金上，比较各房源的真实月付成本**，而不是只比广告价。一个稍微便宜、但水电上限没说清楚的房间，可能比一个稍贵的全包房间更花钱。
6. **不肯书面答复的，直接走人。** 没有东西要藏的营运商，会毫不犹豫地把每个数字给你。回避问题的那一家，其实已经告诉你答案了。

| 步骤 | 该要什么 | 糟糕的答复长什么样 |
|---|---|---|
| 1. 逐项点名，要求书面列出所有费用 | 行政费、清洁费、水电上限和超额费率、冷气保养、提前解约、钥匙或门禁卡、逾期付款 | 「都包含在内」，却给不出清单 |
| 2. 上限和超额都要数字 | 上限是多少元或多少度电，以及超出后每单位的价格 | 「合理使用」 |
| 3. 逐行读提前解约条款 | 金额、会不会与没收押金叠加，以及你要提前多久通知 | 措辞含糊，没有具体数字 |
| 4. 确认费用写进合约，不只是口头讲过 | 文件里的相关条款 | 看房时提过，但从来没写下来 |
| 5. 把每一项已披露的费用加到标价租金上 | 每个房源的真实月付总额 | 只比广告价 |
| 6. 不肯书面答复就走人 | 干脆的数字，毫不犹豫 | 回避问题 |

## 这是给读者的一份底气，不是一次攻击

费用之所以存在，是因为营运一栋共用的楼要花钱，而多数费用是回收真实成本的公道方式，不是用来撑毛利。问题从来不在于有费用。问题在于费用没披露、写得含糊，或者在你已经承诺之后才冒出来。这个市场上的每一家营运商，包括 Lazybee，在特定情况下都会收取标价租金以外的东西。真正保护你这个租客的差别，在于那个「东西」有没有写下来、能不能在你签字之前就问得到答案，而不是签完之后。

## 常见问题：共居合约里的隐藏费用

**新加坡共居最常见的隐藏费用是什么？**
水电上限超额。租金通常包含一定额度以内的电和水，超出的用量会另外收费，但超额费率并不是每次都会主动说明。

**行政费或登记费正常吗？**
可以正常，前提是金额不高，而且在签约之前就说明。只有在签约桌上才第一次出现，或者没有固定金额，才是危险信号。

**是不是所有共居营运商都收提前解约费？**
不是所有，但很多都收。费用本身并不奇怪。关键在于金额和触发条件有没有写进合约，以及会不会与没收押金叠加。

**共居房间要预期有中介费吗？**
直接对接营运商的房源通常没有。中介费在传统由中介经手的整套单位出租上比较常见，在直接挂出房间的共居平台上比较少见。

**两个房源的收费结构不同，我该怎么比较真实成本？**
先把每一项已披露的费用，包括可能出现的水电超额，加到各自的标价租金上，再来比较。单看广告价，看不出真实的月付数字。
