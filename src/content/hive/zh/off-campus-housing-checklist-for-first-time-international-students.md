在新加坡确定租下任何一个房间之前，先用这份清单过一遍：将学生准证的有效期与租期对齐，以书面形式确认押金金额和退还条件，确认租金究竟包含哪些项目，付款前先看房（或走一套正规的远程看房流程），完整阅读租赁合约或许可协议，了解退租的通知期，确认该单位在法律上是否允许住下这么多人，并了解自己的印花税义务。按顺序逐项核对。大多数首次租房的学生吃亏，不是因为犯了某个大错，而是因为漏掉了某个步骤。

本文接下来按阶段拆解每一项：看房前、看房时、签约前，以及贯穿始终的资金与法律检查。

| 阶段 | 目的 | 最常见的疏漏 |
|---|---|---|
| 看房前 | 在房间还没有让你心动之前，先定好自己的底线 | 学生准证只剩 7 个月却签了 12 个月的租约 |
| 看房时 | 在真实的时间点，查看房间的实际状况 | 接受「这跟你的房间是同样户型」而不是亲眼看到自己的房间 |
| 签约前 | 通读整份合约，而不只是别人特意标出来的条款 | 没有用照片或清单记录入住时的房况 |
| 资金与法律 | 大多数首次租房者完全跳过的部分，一旦出错代价也最高 | 没有确认该单位在法律上是否允许住下这么多人 |

## 看房前

在联系中介或预约任何一次看房之前，先完成以下事项。

- [ ] **核实学生准证的有效期。** 查清准证上准确的到期日，而不是大概估算。租期的长短必须以这个日期为准。
- [ ] **让租期与准证有效期对齐，而不是按日历随意定。** 学生准证的有效期通常是一年，或课程时长，两者取较短者，并随学籍每年续签。不要在准证只剩 7 个月时签下 12 个月的租约。
- [ ] **设定一个不只包含租金的月度预算。** 加上交通、餐饮，以及押金和首月租金的预留款。在开始浏览房源之前就算清楚这个数字，而不是等看上某个房间之后才算。
- [ ] **确定离校园的可接受范围。** 先定一个最长通勤时间，再算清楚哪些地铁线路或巴士路线能在这个时间内把你送到学校。要算门到门的实际时间，而不是地图上的直线距离。
- [ ] **列出必须条件和加分条件。** 包含 Wifi、空调、洗衣设施、房门锁等。区分哪些是不满足就直接放弃的，哪些是可以妥协的。
- [ ] **确认你的房东是谁。** 持牌共居营运商、私人房东、二房东转租，这三者的风险等级完全不同。在看房之前先弄清楚自己面对的是哪一种。

## 看房时

看房这一步绝对不能省。如果人在海外无法亲自看房，一定要坚持进行由你本人指挥镜头的实时视频看房，而不是营运商发来的预录视频。预录视频能藏起很多东西，而在实时通话里你可以说「打开那扇门」「让我看看窗户」，这些是藏不住的。

- [ ] **看你实际会住的那间房，而不是「类似」的房间。** 「这跟你的房间户型一样」和真正看到你的房间是两回事。如果那间房暂时无法看，问清楚原因，并要一个具体可以看房的日期。
- [ ] **在你实际会住在那里的时间段查看采光和噪音。** 一间面向大马路的房间，上午 11 点看起来没问题，晚上 11 点听起来完全是另一回事。
- [ ] **用自己的手机实测 Wifi 速度**，而不是听带看的人说一句「Wifi 很好」就相信。
- [ ] **打开每一个柜子，检查床垫，确认空调真的能吹出冷气。** 这些小事很快就会变成天天让你烦心的问题。
- [ ] **算清楚卫浴数量与共用人数的比例。** 要问清楚有多少其他租客共用同一间卫浴，而不只是问单位里有多少间房。
- [ ] **检查自己房间的门锁**，并问清楚其他租客或营运商是否持有备用钥匙。
- [ ] **亲自走一遍从单位到最近地铁站或巴士站的路线。** 房源上标注的距离往往是直线距离，不是实际步行路线。
- [ ] **要求查看厨房和公共区域真实的日常使用状态**，而不是专门为看房布置过的样子。
- [ ] **见一见未来的室友，或至少打听清楚他们的情况。** 年龄范围、是否混合性别、是否也有其他学生。这一点对日常生活的影响，比清单上大多数其他因素都更大。

## 签约前

这一步是整份清单真正发挥作用的地方。签任何东西之前，先读完所有内容。

- [ ] **通读整份租赁合约或许可协议**，而不只是别人特意标出来给你看的条款。如果不确定许可协议和租赁合约的区别，直接问清楚，因为两者的法律保障是不同的。
- [ ] **确认押金金额，以及哪些情况会导致扣款。** 把这些以书面形式确认下来：金额多少、退租时房间需要达到什么状态、搬出后退款的时间安排。
- [ ] **确认租金究竟包含什么。** 水电、Wifi、公共区域清洁，以及任何服务费或中介费，都应该逐项写清楚，而不是靠猜测。
- [ ] **逐件确认哪些是带家具的，哪些不是。** 床、床垫、衣柜、书桌、椅子。不要单凭「已配备家具」这句话就信以为真，要一份清单或现在房间里实际物品的照片。
- [ ] **确认退租的通知期**，如果你签的是没有提前退租条款的固定租期，也要确认这个通知期是否适用于你。具体问清楚，如果课程提前结束或需要在租期结束前搬走，会怎么处理。
- [ ] **确认最短租期。** 新加坡对私人住宅的规定是连续至少三个月，组屋房间出租通常要求最短六个月。确认你的单位适用哪一种。
- [ ] **问清楚合约上还有谁**，以及自己是否需要为其他人未付的租金或造成的损坏承担连带责任。
- [ ] **在搬入自己的物品之前，记录好入住时的房况**，用照片或书面清单都可以。这是日后保护押金的关键依据。
- [ ] **确认维修问题该联系营运商或房东的哪个渠道**，以及通常多久能得到回应。直接问清楚，不要自己假设。

## 资金与法律检查

这是大多数首次租房者完全跳过的部分，一旦出错，代价也是最高的。

- [ ] **了解自己的印花税义务。** 如果你签的是租约或租赁合约，国内税务局(IRAS)会按整个租期总租金的 0.4% 征收印花税，需在签约后 14 天内缴清（如在新加坡境外签约则为 30 天）。按惯例由租客支付，但这一点可以协商，并且应该在合约中写明。如果平均年租金在 S$1,000 或以下，则无需缴纳印花税。合租单位里真正意义上的房间许可可能完全不涉及印花税，因为该税种针对的是拥有独占使用权的租约，而不是许可协议。要弄清楚自己签的究竟是哪一种。
- [ ] **确认该单位在法律上是否允许住下这么多人。** 新加坡的默认上限是每个单位最多六名非亲属住户。部分较大的单位，例如四房式及以上的组屋，或至少 90 平方米的私人单位，可以享有放宽至八人的上限，但前提是业主已经实际完成登记或获得批准。一个超出法定上限的单位，对你自己也是风险，因为它可能在租期中途被查处并被要求停租。
- [ ] **如果是组屋房间或整套单位，要确认房东已获得建屋发展局批准，可以转租给非公民。** 这项批准不是自动获得的。要求出示证明文件，不要只听口头保证。
- [ ] **确认自己的准证在整个租期内（包括结尾的通知期）都仍然有效。** 如果租期中途需要续签学生准证，要在签约之前就向房东说明，而不是事后才提。
- [ ] **妥善保管印花税证明和已签署的合约**，最好同时留一份电子版和纸质版。日后如果出现押金纠纷，这些就是你需要的依据。
- [ ] **在转账之前先核实营运商的资质。** 正规的营运商会要求查看你的准证和在读证明，而不是反过来。如果房东很乐意跳过所有这些审核，这不是省事，而是一个警讯。

| 规则 | 具体规定 | 去哪里确认 |
|---|---|---|
| 最短租期，私人住宅 | 连续三个月 | 房源信息和你的合约 |
| 最短租期，组屋房间 | 通常六个月 | 房东，以及建屋发展局自身的规定 |
| 默认住户人数上限 | 每个单位最多六名非亲属住户 | 直接询问。超出上限的单位可能在租期中途被查处并被要求停租，这也会成为你的问题 |
| 放宽后的住户人数上限 | 八人，适用于四房式及以上的组屋，或至少 90 平方米的私人单位，但前提是业主已实际完成登记或获得批准 | 要求出示证明，而不是口头保证 |
| 组屋转租给非公民的批准 | 不是自动获得的 | 要求出示证明文件 |
| 印花税 | 按整个租期总租金的 0.4% 计算，须在签约后 14 天内缴纳（如在新加坡境外签约则为 30 天）。按惯例由租客支付，但可协商，并应写入合约。若平均年租金在 S$1,000 或以下，则无需缴纳 | 国内税务局(IRAS)。合租单位里真正意义上的房间许可，可能完全不涉及印花税，因为该税种针对的是拥有独占使用权的租约，而不是许可协议 |

## 一条更省事的路径

以上每一项之所以会出现在清单里，都是因为有人先签了字，之后才吃了亏才明白过来。共居可以省掉这里面很多环节：Lazybee 的房间将 Wifi、水电和清洁都打包进同一个价格里，许可协议用通俗易懂的语言写成，而且团队在单位上线之前，就已经处理好了组屋和住户人数上限相关的手续。

如果你不想自己一项项走完整份清单，只想看看校园附近现在有哪些房间，可以到 [lazybee.sg](https://lazybee.sg) 查看当前房源。
